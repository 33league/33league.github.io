Number Fusion · Mobile game · 220 countries

Spend up 6x, cost per install down 17%

We tested six markets, found where the game installed cheapest, then scaled that campaign month after month without raising install costs.

The challenge

Number Fusion is a number-merge puzzle game launching worldwide. The owners needed a large install base quickly, as proof of traction for investors or for handing the app to a team that could grow it.

What we did

  • Ran five language-market campaigns (English, Indonesian, Portuguese, Turkish, Spanish for Brazil) as controlled tests at ₹250 a day each
  • Ran a Global campaign and a separate high-value markets campaign alongside them
  • The Global campaign won, so we paused the weaker tests and moved budget to it month by month
  • Checked that install and in-app events were tracking correctly throughout

The result

38,746 installs from 220 countries in three months. Global installs grew from 2,510 in September to 19,342 in November, while cost per install fell from ₹2.92 to ₹2.41.

  • Six language and market segments tested, with cost per install compared market by market
  • 63% of installs from India, Pakistan, Bangladesh and Indonesia at ₹2.41 to ₹3.64 per install
  • ₹1.50 lakh ad spend managed
